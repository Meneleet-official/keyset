# Keyset 1.0.0 для Minecraft 26.3

Клиентский мод на основе [Keymap от Einjerjar](https://github.com/Einjerjar/keymap).
Визуальное переназначение клавиш, сочетания Ctrl/Shift/Alt и отдельные именованные профили.
Исходная лицензия ISC и авторство сохранены в LICENSE.

## Установка

Нужны Minecraft Java Edition **26.3** и Java **25**.
Выберите один файл под установленный загрузчик:

- Fabric Loader 0.19.5 или новее: `build/mods/keyset-fabric-1.0.0.jar`.
- NeoForge 26.3.0.95 или новее в ветке 26.3: `build/mods/keyset-neoforge-1.0.0.jar`.

Положите выбранный JAR в папку `mods` своего экземпляра игры.
Отдельно устанавливать Fabric API и Architectury не требуется: два небольших модуля Fabric для загрузки ресурсов включены в JAR. На сервер устанавливать мод не нужно.

## Как пользоваться

Откройте настройки игры и нажмите **Keyset** в левом верхнем углу.
Во время игры редактор открывается клавишей под Escape (` / Grave); её можно переназначить.

- Создайте профиль кнопкой **Создать** (**New**). Он копирует назначения активного профиля и сразу становится активным.
- Нажмите на имя активного профиля в верхней панели, чтобы выбрать другой. Переименуйте профиль или удалите его с подтверждением; последний профиль удалить нельзя.
- В окне выбора нажмите **Авто** рядом с профилем, чтобы назначить его текущему миру или серверу. При следующем входе Keyset выберет его сам; повторное нажатие удаляет правило. Для одиночной игры правило привязано к папке мира, для сервера - к адресу.
- Назначьте действие **Следующий профиль клавиш** в редакторе, чтобы переключать профили горячей клавишей. Кнопка **Назад** отменяет последнее изменение привязки или профиля.
- При обычном масштабе слева видны виртуальная клавиатура и фильтры по категориям или модам, справа - поиск и действия. При крупном масштабе GUI или небольшом окне эти панели открываются вкладками «Действия», «Устройства» и «Фильтры». Размер следует настройке интерфейса Minecraft. По умолчанию показаны все действия; заголовки разделов можно сворачивать стрелкой.
- Один клик по действию или его назначению сразу включает захват. Нажмите клавишу/сочетание на физической клавиатуре, кнопку мыши или нужный элемент на экранной схеме.
- **Esc** при выбранном действии полностью снимает назначение вместе с Ctrl/Shift/Alt/Cmd. Кнопка **×** делает то же самое. После назначения или отвязки выбор автоматически снимается.
- Если список был открыт кликом по клавише, Esc сохраняет этот фильтр и положение в списке: можно подряд отвязать несколько действий одной клавиши. После удаления последнего назначения клавиша остаётся выделенной.
- Изменения применяются и сохраняются сразу. Когда действие не выбрано, **Esc** закрывает редактор; кнопка **Закрыть** служит альтернативой и не нужна для сохранения.
- Для сочетаний на экранной схеме используйте кнопки Ctrl/Shift/Alt под клавиатурой. Клик по поиску или категории отменяет текущий захват.
- При наведении на действие или его назначение подсказка показывает название мода. Если источник нельзя определить однозначно, отображается «Неизвестный мод».
- Поиск находит действия, категории, моды и назначенные клавиши; `@litematica` отбирает действия Litematica. Отдельный фильтр показывает конфликты.
- Звезда в строке добавляет действие в избранное, а фильтр **Избранное** оставляет только закреплённые действия.
- Режим **Клавиши** показывает буквенные клавиши, навигацию и цифровой блок; режим **Мышь** открывает схему с ЛКМ/ПКМ, колесом M3, боковыми M4/M5 и дополнительными M6-M8. Подписи клавиатуры переключаются между раскладками.
- По умолчанию действует **Авто**: подписи клавиатуры и назначений выбираются по языку Minecraft. Встроены 136 вариантов, включая русский, украинский, белорусский, французский, немецкий и региональные раскладки. При отсутствии соответствия используется QWERTY. Кнопка раскладки позволяет вручную выбрать QWERTY, ЙЦУКЕН, AZERTY, QWERTZ или Dvorak и вернуться к «Авто».
- Язык меняет подписи физических клавиш, сохраняя коды привязок. Поиск понимает как эти подписи, так и имена кодов клавиш.
- Сброс восстанавливает исходное назначение действия; общий сброс требует подтверждения и затрагивает активный профиль.
- Язык меню следует настройке игры. Включены файлы для всех 143 языковых вариантов Minecraft 26.3: русский и английский вычитаны, большинство остальных переводов созданы автоматически. Региональные варианты могут использовать близкий язык. Для готского, идо, межславянского, ложбана, корнского, науатля Сан-Луис-Потоси, квенья, клингонского, токипоны, волапюка и цоцильского часть строк остаётся на английском; это пока не полный перевод этих языков. Названия действий других модов переводятся самими модами.

Профили сохраняются отдельно от JAR в UTF-8 JSON общей папки Minecraft:
- Windows: `%APPDATA%/.minecraft/config/keyset/profiles.json`.
- Linux: `~/.minecraft/config/keyset/profiles.json`.
- macOS: `~/Library/Application Support/minecraft/config/keyset/profiles.json`.

Все сборки под одной учётной записью используют этот файл. Путь можно переопределить для каждого лаунчера переменной `KEYSET_CONFIG_DIR` или JVM-параметром `-Dkeyset.configDir=...`; укажите каталог, где должны лежать `profiles.json` и папка `transfer`. Версии Keyset читают один и тот же файл, включая старую схему 1.
Избранное и правила автопрофилей хранятся рядом с профилями в `preferences.properties`. Перед сбросом всех назначений, импортом, удалением профиля и отменой создаётся резервная копия `profiles.json` в подпапке `backups` общей папки (до 20 копий). Для ручного восстановления закройте игру и скопируйте нужную копию поверх `profiles.json`.

Чтобы перенести профиль между Fabric/NeoForge или разными каталогами Minecraft, откройте выбор профиля и нажмите **Экспорт**. Отдельный JSON-файл появится в общей папке `config/keyset/transfer/`. Скопируйте эту папку между компьютерами, нажмите **Импорт** в другой сборке и подтвердите добавление профилей. На том же компьютере все сборки увидят профиль автоматически. Текущий профиль при импорте не переключается; затем выберите добавленный профиль в списке.
Файл обмена содержит назначения клавиш, модификаторы, сочетания и настройки Litematica. Совпадающие профили пропускаются, а одинаковые имена получают суффикс. Формат версии 2 переносимый; импорт также принимает файлы версии 1.
В файл входят клавиши мыши и сочетания. Записи отсутствующих модов сохраняются при обновлении профиля.
Запись выполняется через временный файл с атомарной заменой, где её поддерживает файловая система.
При ошибке записи редактор показывает сообщение; выбор профиля и живые назначения откатываются вместе.
Существующий файл из папки конкретной сборки копируется в общую папку при первом запуске, если общей копии ещё нет. Если общая копия уже существует, профили из локального файла добавляются в неё, сохраняя текущий активный профиль. Повреждённый общий файл сохраняется как `profiles.broken-<timestamp>.json` перед созданием нового.

Изменения из стандартного редактора Minecraft также синхронизируются с активным профилем.
Профили старого Keymap 1.18.2 автоматически не импортируются: формат и коды ввода изменились.

Подписи раскладок получены из [архива клавиатур Unicode CLDR 43](https://github.com/unicode-org/cldr/tree/release-43/keyboards/windows).
Их лицензия включена в `LICENSE-KEYBOARD-DATA.txt` и оба JAR. Скрипт `scripts/update_keyboard_layouts.py` обновляет эти данные; при обычной сборке и работе мода сеть для них не используется.

Локализации меню генерируются отдельно скриптом `scripts/generate_localizations.py` на основе каталога языков Minecraft. Скрипт отправляет публичные строки меню в сервис Google Translate; профили и настройки пользователей он не читает. Сам мод и обычная сборка используют готовые локальные JSON и не обращаются к переводчику. Статус каждого перевода указан в `assets/keyset/localization_manifest.json`; автоматические переводы требуют языковой вычитки.

## Litematica / MaLiLib

При установленных Litematica и MaLiLib категория **Litematica** появляется автоматически. В неё входят обычные горячие клавиши и горячие переключатели из Generic/Visuals.

Нажмите действие, зажмите нужное сочетание (например, **M + C**) и отпустите клавиши. Сочетание сохранится сразу; **Esc** полностью отвязывает его. Для сочетаний из нескольких букв используйте физическую клавиатуру. Мышь и модификаторы также поддерживаются.

Профили сохраняют порядок клавиш и настройки MaLiLib: контекст, нажатие/отпускание, дополнительные клавиши и остальные параметры. Обычное переназначение сохраняет эти параметры, а сброс возвращает значения Litematica по умолчанию. Сами дополнительные параметры по-прежнему редактируются в интерфейсе MaLiLib. Переключатели сохраняют своё текущее значение - профили меняют их горячие клавиши.

Привязки применяются через API MaLiLib и сохраняются в собственный конфиг Litematica, а также в профиль Keyset. Изменения, сохранённые через интерфейс MaLiLib, также сразу синхронизируются с активным профилем. Уже настроенные привязки Litematica сохраняются при первом открытии старого профиля без записей этой интеграции. Устанавливать эти моды ради Keyset не требуется.

Совместимость проверяется по API [MaLiLib 26.3](https://github.com/sakura-ryoko/malilib/tree/26.3) и [Litematica 26.3](https://github.com/sakura-ryoko/litematica/tree/26.3). В настоящем клиенте Fabric проверены Litematica 0.29.1 и MaLiLib 0.30.2: все 106 действий, сочетания, Esc, профили, сброс, сохранение, AZERTY и синхронизация с интерфейсом MaLiLib. Также проверен запуск без этих модов. У [Forgematica](https://modrinth.com/mod/forgematica) пока нет версии для NeoForge 26.3, поэтому этот вариант интеграции не проверен; сам Keyset собирается под оба загрузчика.

## Сборка

В Windows:

```powershell
.\gradlew.bat build
```

В Linux/macOS:

```sh
bash ./gradlew build
```

Готовые JAR собираются в `build/mods/`.
Отдельные проверки: `common:test`, `fabric:build`, `neoforge:build`.
Запуск из исходников: `fabric:runClient` или `neoforge:runClient`.
Не запускайте компиляцию параллельно с тестовым клиентом: его классы загружаются из каталога сборки.

Проект закрепляет Gradle 9.6.0, Loom 1.17.20, ModDevGradle 2.0.147 и Java 25.
Версии зависимостей указаны в `gradle.properties` и корневом `build.gradle`.

## Исходники

- `common/src/client/java/dev/keyset` - общий клиент, профили, индекс назначений, раскладки, экран и mixin-интеграция.
- `common/src/client/resources` - общие ресурсы и локализации.
- `common/src/test/java` - независимые тесты хранения профилей.
- `fabric/src/client`, `neoforge/src/client` - метаданные и адаптер загрузчика.

Старые каталоги `common/src/main`, `fabric/src/main` и `forge` оставлены как исходный материал Keymap 1.18.2.
Они **не включаются** в сборку 26.3; модуль Forge заменён модулем NeoForge в настройках Gradle.
